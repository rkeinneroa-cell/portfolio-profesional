# Jesús Lezama Fitness Club

Plataforma web para la **gestión administrativa y operativa de un gimnasio**, permitiendo administrar clientes, membresías, clases, horarios, instructores y locales desde un panel de administración.

## Tecnologías

Angular · JavaScript · TypeScript · Tailwind CSS · Supabase · PostgreSQL

## Desarrollo realizado

* Rediseño de la interfaz bajo requerimientos del cliente, aplicando un enfoque **minimalista, responsive e interactivo** mediante Tailwind CSS.
* Desarrollo de **nuevos componentes, módulos y funcionalidades**, incluyendo formularios, validaciones y operaciones CRUD.
* Diseño y modificación del **modelo de datos**, incorporando nuevas tablas y tablas intermedias para gestionar relaciones entre entidades.
* Desarrollo del módulo de **horarios y clases**, incluyendo calendario, asignación de clientes e instructores y gestión de eventos.
* Optimización de consultas complejas mediante **funciones RPC en PostgreSQL**, trasladando lógica y consultas extensas desde los servicios hacia la base de datos.
* Creación y consumo de **Supabase Edge Functions** para procesos backend.
* Componentización y reutilización de funcionalidades para mejorar la mantenibilidad del frontend.
* Corrección de errores, validaciones y mejora de funcionalidades existentes.
* Implementación de reportes.
